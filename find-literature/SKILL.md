# 查找文献

检索 Crossref 学术数据库，生成可直接粘贴进论文的 GB/T 7714 格式参考文献。

## 核心原则

引用文本由 `find_lit.py` 从 Crossref 返回的**结构化元数据程序化生成**，不是语言模型凭记忆撰写的。这样做的目的是避免编造不存在的文献。**不要自己手写或"修正"引用内容** —— 一切以脚本输出为准。

## 执行步骤

1. **拿到查询词**。来自用户输入（如 `/find-literature "图神经网络"`）。如果没有提供，就先问用户想查什么方向或标题。

2. **运行脚本**：

   ```bash
   python3 "${CLAUDE_SKILL_DIR}/find_lit.py" "<查询词>" --max <条数>
   ```

   （`${CLAUDE_SKILL_DIR}` 由 Claude Code 替换为本 skill 所在目录，无需写死绝对路径。）

   - `--max` 默认 10，用户想要更多时显式传入（上限 100）。
   - `--out` 默认输出到**当前目录下的 `literature/` 子文件夹**，一般不用改。
   - 想走 Crossref 礼貌池，运行前设 `CROSSREF_MAILTO=你的邮箱`；不设也能用。
   - 查询词用引号包起来，避免空格被 shell 拆开。

3. **回报结果**：把脚本打印出的 txt 文件路径原样告诉用户，并说明找到几条。

4. **不确定查询词够不够好时**：先跑一次看结果质量。如果返回的多是预印本或会议摘要而非目标文献，建议用户改用更具体的英文关键词再跑一次——Crossref 对英文术语的匹配明显更好。

## 输出格式说明

生成的 txt 里每条包含：

```
[1] 作者. 题名[J]. 刊名, 年, 卷(期): 页码.
     类型: journal-article | DOI: 10.xxxx/yyyy
```

- 类型码：`[J]` 期刊、`[C]` 会议、`[M]` 专著、`[D]` 学位论文、`[EB/OL]` 预印本/网络资源
- 专著按 GB/T 7714 著录出版项：`作者. 书名[M]. 出版地: 出版者, 出版年.`；Crossref 缺字段时自动省略
- 作者规则：≤3 人全列，>3 人取前 3 加"等"（中文）或"et al."（英文）
- 那个"类型 + DOI"的次要行是给你核对真伪用的，粘进论文时记得删掉

## 必须向用户说明的两点

1. **Crossref 的检索相关性一般**。它按匹配度排序，可能混入预印本（`posted-content`）、书章、甚至不相关的条目。让用户按次要行的类型自己筛。
2. **引用仍建议逐条核对**。元数据来自出版社登记，绝大多数可靠，但个别条目的卷期页码可能缺失或有误。DOI 是核对的入口。

## 常见问题

- **报错"网络连接失败"** —— 检查网络，Crossref 在部分网络环境下需要代理。
- **结果为空** —— 换关键词；中文查询命中率低于英文。
- **脚本文件不存在** —— 确认 `${CLAUDE_SKILL_DIR}` 指向技能目录（符号链接失效时最常见）。
