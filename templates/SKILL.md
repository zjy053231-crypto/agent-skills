# 技能标题

## 核心原则

这个技能最关键的一条是什么？为什么必须这么做？
把"不这么做会出什么错"写出来——这比单纯写"应该怎么做"更能让人（和 AI）记住。

## 执行步骤

1. **第一步**：做什么，怎么做。
2. **第二步**：如果要跑脚本：

   ```bash
   python3 "${CLAUDE_SKILL_DIR}/你的脚本.py" "<参数>"
   ```

   `${CLAUDE_SKILL_DIR}` 会自动替换成这个技能文件夹的路径，不用写死。

3. **第三步**：结果怎么解释、怎么回报给用户。

## 必须向用户说明的

哪些事情是你知道但用户不知道的？哪些限制必须提前讲清楚？
比如"这一步的结果没经过实际验证""这个格式在某个软件里不支持"。
宁可说清楚，不要让用户踩坑。

## 常见问题

- **报错 XXX** —— 原因和解决办法。
- **结果不对** —— 怎么排查。
